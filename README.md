# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop built with React and Redux Toolkit.

## Features

- **Landing page** with the company name, a background image, an About Us section, and a "Get Started" button.
- **Product listing page** with houseplants grouped into categories. Each plant shows a thumbnail, name, description, and price, with an "Add to Cart" button that disables once the plant is in the cart.
- **Navbar** on the product and cart pages, with links to Home, Plants, and Cart, plus a cart icon showing the live item count.
- **Shopping cart page** that shows each plant's thumbnail, name, unit price, and total cost, with buttons to increase, decrease, or delete items. It also shows the total cart amount, a "Continue Shopping" button, and a "Checkout" button (coming soon).

## Tech stack

- React (Vite)
- Redux Toolkit and React Redux

## Run locally

```bash
npm install
npm run dev
```
